# Database Architecture History

Each `DB-ARCH-X.Y/` directory is an immutable architecture snapshot.

A history folder may be created while that architecture is still current to establish a durable baseline before documentation-layout changes. Its presence under `history/` does **not** by itself mean the architecture is retired.

Always use [../CURRENT.yaml](../CURRENT.yaml) to determine what production currently runs.

Do not edit archived architecture files during normal maintenance. Record historical corrections in the global [../CHANGELOG.md](../CHANGELOG.md).
